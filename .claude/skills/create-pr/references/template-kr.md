# PR 본문 템플릿 (한국어)

아래 구조를 그대로 사용한다. 해당 없는 섹션은 `없음`으로 둔다. 제목은 `타입: 요약` (예: `feat: 프롬프트 500자 제한 검증 추가`).

```markdown
## 요약
<!-- 이 PR이 무엇을 왜 바꾸는지 1~3문장 -->

## 변경 사항
<!-- 주요 변경을 항목별로. 파일 나열이 아니라 동작·구조의 변화를 쓴다 -->
-
-

## 변경 이유
<!-- 배경, 해결하려는 문제, 선택한 접근과 버린 대안 -->

## 테스트
<!-- 실제로 실행한 명령과 결과만 적는다. 실행하지 않았다면 그렇게 쓴다 -->
- [ ] `bun run test`
- [ ] `bun run build`

## 리뷰어 참고
<!-- 중점적으로 봐야 할 부분, 알려진 한계, 후속 작업. 없으면 `없음` -->
```
