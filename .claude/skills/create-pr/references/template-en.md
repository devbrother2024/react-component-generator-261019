# PR Body Template (English)

Use this structure as-is. Put `N/A` in sections that do not apply. Title format is `type: summary` (e.g. `feat: add prompt length validation`).

```markdown
## Summary
<!-- 1-3 sentences: what this PR changes and why -->

## Changes
<!-- Group by behavior or structure, not a file listing -->
-
-

## Motivation
<!-- Background, the problem being solved, the approach chosen and alternatives rejected -->

## Testing
<!-- List only commands you actually ran, with results. If you did not run them, say so -->
- [ ] Test suite
- [ ] Build / type check

## Notes for reviewers
<!-- Areas that need close attention, known limitations, follow-ups. `N/A` if none -->
```
